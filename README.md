# Exploring Network Layers 1 & 2 🌐🔌

## Welcome to My Network Journey! 🚀

In this project, I took a deep dive into **Network Layers 1 (Physical) and 2 (Data Link)** to understand how data is transmitted across networks. Using tools like **Packet Tracer**, I explored the physical media, topologies, and protocols that form the foundation of modern networking. If you’re curious about how devices communicate over wired or wireless connections, this guide will walk you through the essentials.

---

## What Was I Doing? 🤔

This assignment focused on understanding the services provided by Layers 1 and 2 of the OSI model and their role in network communication. Here’s what I tackled:
- **Physical Layer (Layer 1)**:
  - Explored transmission media like twisted pair cables, coaxial cables, fiber optics, and wireless technologies.
  - Examined topologies such as bus, ring, star, mesh, tree, and hybrid.
- **Data Link Layer (Layer 2)**:
  - Learned about MAC addresses, ARP (Address Resolution Protocol), and Ethernet frames.
  - Simulated ARP operations to map IP addresses to MAC addresses.
  - Analyzed Ethernet frame structures and how switches facilitate network connectivity.
- **Protocols**:
  - Investigated TCP/IP protocols like ARP, Ethernet (IEEE 802.3), WLAN/WiFi (IEEE 802.11), Bluetooth (IEEE 802.15), and WiMax (IEEE 802.16).

Through hands-on labs, I gained practical experience in configuring networks, simulating ARP, and examining Ethernet frames using Packet Tracer.

---

## Tools Used 🔧

1. **Packet Tracer**: A powerful simulation tool for designing and testing network topologies.
2. **Command Line**: Used commands like `ipconfig /all` to discover MAC addresses and ARP tables.
3. **Ethernet Standards**: Explored IEEE 802.3 standards for Ethernet, including Fast Ethernet, Gigabit Ethernet, and 10 Gigabit Ethernet.
4. **ARP Simulation**: Simulated ARP requests and responses to map IP addresses to MAC addresses.
5. **Frame Analysis**: Examined Ethernet frame structures, including headers, payloads, and CRC for error detection.
